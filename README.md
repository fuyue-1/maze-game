# 🐉 小龙迷宫逃生 · Dragon Maze

一个纯前端实现的迷宫逃生网页游戏（主角是一只小奶龙）。**无需服务器、无需数据库、打开即玩。**

核心亮点：**迭代 DFS 迷宫生成 · BFS 怪物寻路 · 局部 BFS + 视线追踪迷雾 · Canvas 矢量角色**

> 🎮 在线试玩：`https://<你的用户名>.github.io/maze-escape/`

## 玩法

- 从左上角出发，抵达右下角发光的 **出口**
- 黑暗中只能看到身边一小圈，走过的路留下暗淡轮廓
- **怪物**始终知道你的位置，沿最短路径逼近
- 难度越高，迷宫越大、怪物越多、视野越窄

| 难度 | 迷宫 | 怪物 | 视野 |
|------|------|------|------|
| 简易 | 11×11 | 1 | 6.5 格 |
| 中等 | 17×17 | 2 | 5.5 格 |
| 困难 | 25×25 | 3 | 4.5 格 |

**操作**：`WASD` / 方向键移动，`空格` 隐身，`ESC` 暂停；移动端滑动屏幕或点右下方向键（支持按住连走）

**个性化**：6 款龙皮肤 + 4 套场景主题，实时预览，设置自动保存到本地。

**隐身技能**：空格 / 点 HUD「隐身」按钮触发，持续 5 秒、冷却 20 秒；期间怪物完全看不见你（即使面对面），正在追击的怪物立即转入搜索；角色三种视角下均半透明显示；冷却转好自动 toast 提示。

**怪物 AI**：视线感知状态机（idle / chase / search）——怪物只能看见"视力范围内 + 视线通畅"的玩家，拐角后即失明；丢失视线后前往最后目击位置搜索，记忆耗尽转为游荡。难度越高视力越远、记忆越久。

**辅助系统**：右上角半透明小地图（只显示已探索区域 + 始终可见的金色出口菱形）；走进死路时自动红色 ✕ 标记（主画面动画 + 小地图永久标记），降低试错成本但不破坏迷雾紧张感。

## 技术实现

### 1. 迭代式 DFS 迷宫生成（`js/maze.js`）

- 迷宫用 `(2N+1)×(2N+1)` 二维数组表示，偶数行列是墙、奇数行列是房间
- 用**显式栈**替代递归，避免大迷宫爆栈（测试通过 120×120 房间 = 241×241 网格）
- 每次只打通"当前房间 ↔ 未访问房间"的墙 → 生成树 → **单连通、无环、必有通路**
- `validateMaze()` 校验连通性、无环（无 2×2 通路块）、通路格数恰为 `2cr + (cr-1)`

### 2. BFS 怪物寻路（`bfsPath`）

- 每只怪物每 0.25 秒做一次 BFS，得到到玩家的最短路径并缓存逐步消费
- 用 `Int32Array` 一维数组做 visited/parent，避免对象哈希开销
- 完美迷宫无环 → BFS 结果即唯一最短路，**无需 A\***
- 实测单次 BFS 0.064ms（45×45），3 只怪物每帧合计 < 0.3ms

### 3. 迷雾视野（`js/los.js`）

两层约束叠加，解决"圆形视野穿墙"问题：

- **局部 BFS**（`bfsReachable`）：以玩家为圆心，限制 BFS 步数 = 视野半径
- **Bresenham 视线追踪**（`hasLineOfSight`）：对每个候选格做直线通视检测，隔墙不可见

另有 `ExploredMap`（Uint8Array 位图）记录"走过但当前看不见"的区域，形成战争迷雾记忆层。

### 4. 渲染分层（`js/render.js` + `js/sprites.js`）

- **数据/绘制分离**：`themes.js` 只放配色与体型参数，绘制代码零硬编码颜色
- 迷宫墙体预渲染到离屏 canvas，每帧只 `drawImage` 一次
- 迷雾用 `destination-out` 合成模式在纯黑层上挖出柔光洞
- 角色全部 Canvas 矢量绘制（贝塞尔曲线），无图片资源，任意缩放不失真
- 移动用 `easeOutQuad` 插值、`dt` 驱动，**帧率无关**

### 5. 小地图与死路标记（`js/minimap.js` + `js/helpers.js`）

为缓解"视野紧张 + 完美迷宫窄走廊"带来的试错成本，在不破坏迷雾玩法的前提下加了两个辅助系统：

- **右上角半透明小地图**（148px，移动端 104px）：只画**已探索区域**（不剧透未走过的路），含最近 30 步轨迹、视野内怪物红点、**金色菱形出口（始终显示）**、玩家光晕
- **死路自动标记**：`helpers.js` 扫描全图严格死胡同（仅 1 个相邻通路，占比约 5%）；玩家**走进死路瞬间**触发主画面红色 ✕ 扩散动画 + toast 提示，并在小地图上永久标红 ✕
- 判定分两层：`isCulDeSac`（全图扫描）与 `isDeadEndAt`（带来路排除的实时判定），避免"刚走进来就算死路"的误报

### 6. 三视角渲染（`js/render.js` + `js/iso.js` + `js/iso3d.js`）

- **2.5D 等距（默认）**：标准 2:1 dimetric 投影，墙体是真立方体（顶面 + 双侧面 + 方向光），深度按 `(x+y)` 排序；大迷宫自动切换**镜头跟随模式**（指数平滑，帧率无关），小迷宫整图装入
- **2D 俯视**：原有平面视角，墙体预渲染离屏层（默认）
- **真 3D（Three.js）**：`vendor/three.min.js` 本地内置，无需 CDN；墙体/地板 InstancedMesh 单次 draw call；跟随相机 + 距离雾 + 玩家点光源；WebGL 不可用自动降级 2D
- 外观设置里一键切换，偏好存 localStorage；两套渲染读同一份 `state`，游戏逻辑零改动
- 玩家格周边 2 格内的墙强制提前绘制，避免等距视角下南/东墙挡住角色；脚下加轮廓微光兜底

### 7. 排行榜（`js/bmob.js`）

游戏逻辑 100% 在浏览器，后端只用 BaaS 存排行榜。**三级降级策略**保证演示不卡死：

```
云端可用 → 写入 Bmob rank 表
   ↓ 失败/超时(6s)
自动降级 → localStorage 本地榜
   ↓
界面标注数据来源，诚实不装
```

配置：打开 `js/bmob.js`，填入 `APPLICATION_ID` 与 `REST_API_KEY`。不配也能玩（本地榜）。

## 目录结构

```
maze-game/
├── index.html              # 页面结构
├── css/style.css           # 深色主题样式
├── js/
│   ├── maze.js             # 迷宫生成 + BFS 寻路（纯函数，可 Node 测试）
│   ├── los.js              # 视线追踪 + 迷雾 + 已探索地图
│   ├── themes.js           # 主题/皮肤配置（数据驱动）
│   ├── sprites.js          # 角色矢量绘制
│   ├── helpers.js          # 死路检测（全图扫描 + 实时判定）
│   ├── minimap.js          # 右上角半透明小地图
│   ├── iso.js              # 等距 2.5D 投影与渲染（纯函数可 Node 测试）
│   ├── iso3d.js            # 真 3D 渲染层（Three.js）
│   ├── render.js           # 渲染分发（2D/2.5D 双后端）
│   ├── game.js             # 状态机 / 主循环 / 怪物 AI / 碰撞
│   ├── bmob.js             # 排行榜（云 + 本地降级）
│   └── main.js             # UI 编排层
├── tests/
│   ├── maze.test.js        # 55 项算法测试
│   └── los.test.js         # 24 项视线/迷雾测试
└── standalone.html          # 单文件版（全部内联，可离线分享）
```

## 本地运行

```bash
# 方式一：双击 index.html（最简单）
# 方式二：起本地服务（推荐，便于调试）
python3 -m http.server 8080
# 打开 http://localhost:8080
```
